# RESEARCH -- protocol

Mandatory before GENERATE when the task is external (open call, venue, commission) and there is no ready territory. Do not start GENERATE for an external task without `research-notes` -- this is a hard rule from SKILL.md.

## Steps

**(a) Task material.** Read the brief/selection criteria in full, write out the explicit criteria as a list -- not a summary, a list of checkable requirements.

**(b) Competitive field.** Map 5-10 existing works/communications in this field -> which positions are already taken -> find the emptiest quadrant relative to the real (not assumed) discourse of the category -> take it as the candidate positional territory.

**(c) Cultural gap.** The category's departing orthodoxy vs. an ideology maturing on the periphery -- a source of meaning unreachable by averaging over the corpus; look for meaning where a model does not go by default.

**(d) Audience competence inventory.** For every figure (metaphor, pun, reference), write out what knowledge the viewer/jury needs. Flag metaphors and puns as fragile separately -- they break first, and silently: the audience does not report "I didn't get it," it simply walks past. If the key meaning rests on one such figure, provide a fallback channel.

**(e) Residue.** What in the material does not fit the first frame that comes to mind -- this is a signal to change the frame, not scrap material to discard.

## Output

`research-notes`, 5-15 lines:
- explicit brief criteria (list);
- candidate territory (empty quadrant) + why it is empty;
- cultural gap: what is departing / what is maturing;
- competence inventory + which figures are fragile;
- residue, if found.

`research-notes` is an input to GENERATE, not directly to TRANSLATE.
