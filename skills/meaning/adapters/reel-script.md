# Adapter: video script (reel / short / video essay)

A script is not text with timecodes -- it is a **sequence of changes in the viewer**:

```
Before watching, the viewer thinks X
      |
The hook puts X in doubt
      |
The observation shows Y
      |
The turn connects X and Y
      |
The ending leaves the viewer with Z
```

Mapping onto the map: X <- `counter_reading`/background, Y <- `observation`, the turn <- `tension`, Z <- `claim` + `audience_shift`.

## Checks (AUDIT) / requirements (TRANSLATE)

- Is the X -> Y -> Z chain filled in? An empty link is a hole in the script, not "stylistic roughness."
- Does the hook attack X specifically (what the viewer actually thinks), not an abstract intrigue?
- **Does the image carry meaning?** Test: remove the voiceover -- does even part of the thesis read from the picture/edit? If not, this is an essay read over random B-roll (a layer-6 failure).
- Every scene/beat: what does it change in the viewer's head? A scene with no change gets cut.
- Does the ending deliver Z, not a repeat of the hook?

## TRANSLATE output format

```
X (what the viewer thinks before):
Hook (scene + text):
Y (observation; how it's shown on screen):
Turn (how X and Y connect; how it's shown):
Z (what the viewer leaves with):
Beats: [scene -> what's on screen -> what's in the text -> what changes for the viewer]
```
