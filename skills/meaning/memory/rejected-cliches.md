# Cliche graveyard

Phrasings forbidden in GENERATE/TRANSLATE until a **concrete mechanism** (what exactly, and how it works) is presented. Topics are not forbidden -- empty phrasings in place of meaning are.

Rule for adding entries: whenever the user rejects a phrasing as empty -- add it here (with the user's consent, with a date).

Entry format:

```
- [YYYY-MM-DD] "phrasing" -- why it's empty / what to require instead
```
