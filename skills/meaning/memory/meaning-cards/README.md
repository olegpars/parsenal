# Meaning card archive

After the author approves a Meaning Map -- save a card here (with the user's consent).

File name: `YYYY-MM-DD-slug.md` (slug -- a short name for the work/material, in latin characters).

## Card format

```markdown
# <Title of the work/material>

Date: YYYY-MM-DD * Format: post | script | artwork | open call | ...

## Approved Meaning Map
(the full YAML map, with [S]/[I]/[N] tags)

## Rejected directions
- direction + why it was rejected

## Decisions and critique
- key decisions by the author, critique notes

## After publication/showing (filled in later)
- how the meaning changed after release
```

Read the archive during GENERATE and SELECT -- to see how the author's questions develop over time, instead of starting from zero every time.
