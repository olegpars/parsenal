# Recurring author questions

Not topics ("AI, nature, insects"), but **questions** the author keeps returning to across different works.

Rule for adding entries: a question belongs here once it has resurfaced for the **2nd time or more** across different works/maps. Add with the user's consent, one line per question, with a date and links to the cards where it appeared.

Entry format:

```
- [YYYY-MM-DD] Question? (cards: slug1, slug2)
```
