## Anti-patterns -- read before generating any lore

- **Worldbuilder's disease** -- endless lore development instead of finished stories; the symptom is expanding backstory/systems/maps while production never actually starts. The cure is production constraints: this file = "narrative pillars" instead of department needs, `04-continuity-log.md` = change control, the release schedule = deliverables.
- **Lore inflation** -- an LLM or author keeps adding factions, gods, objects, twists without limit. Filter rule: see the stopping rule in the README ("don't build an element unless it affects the current story...").
- **Identity drift** -- characters/creatures gradually turn into approximate archetypes instead of specific individuals. Cured by hard-locking visual identifiers and "disallowed variations" in `02-records/creature.md`.

General risk diagnosis: AI makes expansion cheap and curation expensive. The fix isn't a longer prompt but stronger art direction, provenance, and editorial refusal (a deliberate choice not to add something).
